- Kiểm toán Apps Script được Guard chứng nhận đã khảo sát 15 Cloud projects; `nmh-maps` ACTIVE nhưng `routes.googleapis.com` và `places.googleapis.com` hiện DISABLED trong bằng chứng kiểm toán gần nhất.

Thử cập nhật dự án kiểm toán để mở rộng kiểm tra đã bị Guard BLOCK và không thực hiện mutation.
- Chưa xác minh Billing của `nmh-maps` đã gắn tài khoản/đủ quota. Chưa enable API, chưa tạo hoặc nạp Google key; OpenAI API key riêng cũng chưa có trong cấu hình Worker.

- Khi quyền xong: kiểm tra billing/limit tại `nmh-maps`; bật Routes/Places (New) và tạo server API key chỉ được phép hai API; ghi key vào Worker qua secret; tạo OpenAI key riêng; sử dụng auth token đủ mạnh. Không lưu giá trị khóa vào GitHub repo, log hoặc cuộc trò chuyện.
