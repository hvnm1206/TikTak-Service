D. WORKFLOW REGISTRY

Vision: Analyze Webhook → Prepare Vision Request → OpenAI Vision → Parse Vision Result → Return Vision.

TTS: TTS Webhook → Prepare TTS → OpenAI TTS → Encode Audio → Return TTS.

Frontend: mở camera → sampling cục bộ 250 ms → giữ frame mới nhất → one-frame Vision PERCEPTION → stale-response gate → consistency gate → DECISION layer → fast local voice.

E. DATA / AI RULES

  • Vision model: gpt-5.6-luna.
  • Reasoning: none; max output: 160.
  • Vision PERCEPTION output: {description, sceneMemory, shouldSpeak, distanceBand, pathBlocked, obstaclePosition, freePath, motionRisk, confidence}. GPT không còn trả action trái/phải.
  • Scene memory ngắn để giảm lặp và nhận thay đổi cảnh.
  • distanceBand: far / mid / near / immediate / unknown. Không ép AI đo mét tuyệt đối.
  • pathBlocked chỉ true khi vật thực sự nằm trên hướng đi dự kiến.
  • DECISION layer nằm ở frontend: stop/wait/slow/veer_left/veer_right/continue/scan được suy ra từ perception, không lấy trực tiếp từ GPT.
  • stop chỉ hợp lệ khi distanceBand=immediate + pathBlocked, hoặc nguy cơ động immediate. Lệnh trái/phải phải được cùng freePath xác nhận 2 response liên tiếp.
  • Stale không còn đồng nghĩa vô dụng: app xác nhận perception geometry qua 2 response liên tiếp. Nếu freePath/pathBlocked ổn định với confidence đủ cao, response stale vẫn được dùng cho Decision. Nếu chưa ổn định thì chỉ hiển thị 'Đang xác nhận lối', không phát điệp khúc fallback.
  • urgency: normal / caution / danger để điều chỉnh nhịp quan sát; shouldSpeak quyết định có phát giọng nói hay im lặng; voiceInstruction cực ngắn 3–8 từ để phát ngay.
  • Ưu tiên hiện tại: xác định vật/nguy cơ trên hướng đi → phân loại distanceBand → xác định pathBlocked → chọn action → mới sinh câu nói. Không dùng 'thấy vật cản' đồng nghĩa với 'Dừng lại'.
  • TTS model backend: gpt-4o-mini-tts; voice marin; format wav; speed 1.02. Auto guidance ưu tiên speechSynthesis nội bộ iPhone để giảm 2–6 giây latency backend.
  • TTS instruction: nói tiếng Việt tự nhiên, liền câu, ngắt theo dấu câu, không đọc từng từ, không đánh vần, không thêm nội dung.
